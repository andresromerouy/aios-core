# Story 1.2: Install Payload CMS 3.0 embebido en Next.js

## Status

Draft

## Story

**As a** dueño-dev,
**I want** Payload CMS 3.0 instalado dentro del mismo proyecto Next.js compartiendo el runtime,
**so that** el admin y el sitio público comparten un solo deployment sin servicios separados.

## Acceptance Criteria

1. Payload CMS 3.x instalado siguiendo la guía oficial de integración con Next.js App Router.
2. Estructura de carpetas creada: `src/collections/` (vacía aún excepto `Users.ts`), `src/payload.config.ts`.
3. Configuración mínima de Payload sin collections de negocio (sólo `Users` por default, sin TOTP aún).
4. Ruta `/admin` levanta el panel de Payload (puede estar pidiendo DB connection o usando SQLite temporal — DB real llega en Story 1.3).
5. Build local (`pnpm build`) compila sin errores ni warnings críticos.
6. **Spike R7 ejecutado y documentado:** validar que Payload 3.x + Next 15 + RSC funcionan en conjunto. Si surgen bugs conocidos, documentar versión específica que funciona en `docs/operations/known-issues.md` y pinear esa versión.

## Story Points

**5 pts** (complejo, 3-6h focused). Incluye spike R7 que puede absorber tiempo significativo.

- [ ] **Task 3 — Crear `payload.config.ts` mínimo** (AC: 3)
  ```typescript
  // src/payload.config.ts
  import { buildConfig } from 'payload';
  import { postgresAdapter } from '@payloadcms/db-postgres';
  import { lexicalEditor } from '@payloadcms/richtext-lexical';
  import path from 'path';
  import { fileURLToPath } from 'url';

  const filename = fileURLToPath(import.meta.url);
  const dirname = path.dirname(filename);

  export default buildConfig({
    admin: {
      user: 'users',
    },
    collections: [
      {
        slug: 'users',
        auth: true,
        fields: [
          // Email + password vienen por default cuando auth: true
        ],
      },
    ],
    editor: lexicalEditor({}),
    db: postgresAdapter({
      pool: {
        connectionString: process.env.DATABASE_URL || '',
      },
    }),
    secret: process.env.PAYLOAD_SECRET || '',
    typescript: {
      outputFile: path.resolve(dirname, '../payload-types.ts'),
    },
  });
  ```
