# Story 1.8: Página canary pública "El Mate Digital — Próximamente"

## Status

Draft

## Story

**As a** dueño,
**I want** una página pública con branding mínimo y mensaje de "próximamente" desplegada en producción,
**so that** valido que toda la cadena (Next + Payload + Neon + Vercel + Cloudinary stub) funciona end-to-end y puedo compartir un URL real con cualquiera.

## Acceptance Criteria

1. Página `/` (home) renderiza un hero con título "El Mate Digital", subtítulo y mensaje "Próximamente — un blog Apple en español con mate de por medio".
2. Renderiza correctamente en modo claro y oscuro respetando los tokens de la Story 1.7.
3. Incluye `<meta>` básicos (`title`, `description`, `og:title`, `og:description`) — los advanced OG/JSON-LD llegan en Story 3.6.
4. Lighthouse mobile ≥90 en Performance, SEO y Accessibility para esta página (validado en el preview de Vercel).
5. Página accesible públicamente desde el URL de Vercel de producción con HTTPS.
6. README del proyecto enlaza al URL canary de producción.
7. El theme toggle (Story 1.7) está visible y funcional.
8. Layout responsive básico: legible en móvil + desktop.

## Story Points

**2 pts** (simple, 15-45 min).

## Dev Notes

### Esta es la PRIMERA pieza VISIBLE del producto

Tras esta story, el dueño puede:
- Compartir un URL público con amigos/colaboradores como prueba de vida del proyecto.
- Validar que toda la cadena tech funciona en producción real.
- Empezar a iterar UX con feedback temprano.

### Layout decisions deliberadas

- Sin imágenes (Cloudinary stub no necesario en esta story).
- Sin ads (Story 5.x).
- Sin newsletter signup (Story 4.x).
- Solo texto + theme toggle = layout mínimo que valida tokens + fonts + deploy.

### Próximos pasos esperados

- En Story 3.1 esta página se convierte en el verdadero home con Header/Footer completos.
- El contenido placeholder se reemplaza por hero con featured post + grid de últimas publicaciones (Story 2.8).

### Testing

- Sin tests automatizados.
- Validación: Lighthouse mobile ≥90 + smoke test manual responsive + toggle funcional.
