# Story 1.1: Scaffold Next.js 15 + TypeScript estricto + Tailwind + shadcn/ui

## Status

Draft

## Story

**As a** dueño-dev,
**I want** un proyecto Next.js 15 con App Router, TypeScript estricto, Tailwind CSS, shadcn/ui y Lucide ya configurados desde cero,
**so that** tengo una base limpia y consistente sobre la cual construir el resto del producto sin reconfigurar boilerplate.

## Acceptance Criteria

1. Repo nuevo creado (nombre `el-mate-digital`) con README mínimo, `.gitignore`, `LICENSE` (MIT) y estructura de carpetas inicial.
2. `package.json` declara Next.js 15.x, React 19.x, TypeScript ≥5.6, Tailwind ≥3.4, ESLint flat config 9.x, Prettier 3.x, **pnpm como package manager**.
3. `tsconfig.json` con `"strict": true`, `"noImplicitAny": true`, `"noUncheckedIndexedAccess": true`, paths aliases (`@/*` → `./src/*`).
4. `pnpm dev` levanta servidor local en `http://localhost:3000` y muestra una página default de Next.js.
5. shadcn/ui inicializado (`pnpm dlx shadcn@latest init`) con base styles + el componente `Button` instalado y renderizable.
6. Lucide React (`lucide-react`) instalado y un ícono renderizable como smoke test.
7. ESLint + Prettier corren limpios (`pnpm lint`, `pnpm format`) sin errores.
8. Estructura de carpetas conforme a Architecture §8.1 + §10 (creada vacía donde no haya código aún).
