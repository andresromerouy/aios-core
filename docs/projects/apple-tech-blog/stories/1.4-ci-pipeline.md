# Story 1.4: Pipeline CI con GitHub Actions

## Status

Draft

## Story

**As a** dueño-dev,
**I want** un pipeline de CI que valide lint, typecheck y tests en cada PR,
**so that** ningún cambio se mergea sin pasar las gates de calidad mínimas.

## Acceptance Criteria

1. Workflow `.github/workflows/ci.yml` se ejecuta en `pull_request` (cualquier branch a `main`) y `push` a `main`.
2. Steps incluyen: install (con cache de `pnpm`), `pnpm lint`, `pnpm typecheck`, `pnpm test` (placeholder Vitest si aún no hay tests reales — pasa con `--passWithNoTests`).
3. CI corre en Node ≥20 LTS.
4. Status checks de "lint", "typecheck" y "test" exigidos para merge a `main` (branch protection rule activa).
5. Documentado en README cómo correr los mismos checks localmente.
6. CI completa en <3 minutos en el caso típico.

**3 pts** (estándar, 1-3h focused).

## Dev Notes

### Workflow ci.yml completo (Architecture §12.2)

```yaml
# .github/workflows/ci.yml
name: CI

on:
  pull_request:
    branches: [main]
  push:
    branches: [main]

jobs:
  lint:
    name: Lint
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'
      - run: pnpm install --frozen-lockfile
      - run: pnpm lint

  typecheck:
    name: Typecheck
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'
      - run: pnpm install --frozen-lockfile
      - run: pnpm typecheck

  test:
    name: Test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v3
        with:
          version: 9
      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'pnpm'
      - run: pnpm install --frozen-lockfile
      - run: pnpm test
```

### Notas operativas

- **No se incluye E2E** en este workflow — Playwright corre en `.github/workflows/e2e.yml` separado, solo en `main` (Story 6.7).
- **Tests de integración Payload** corren en `pnpm test` cuando se sumen (Story 2.x); por ahora solo unit.
- **Build step** está en el deploy de Vercel (Story 1.5), no en este CI — duplicar `pnpm build` sería redundante.

### Testing

- **Sin tests automatizados** — esta story es config.
- Validación: el PR de esta misma story debe pasar todos los checks verdes.
