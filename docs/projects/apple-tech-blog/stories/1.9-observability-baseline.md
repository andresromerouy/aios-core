# Story 1.9: Observabilidad baseline (logging + Sentry + Speed Insights)

## Status

Draft

## Story

**As a** dueño-dev,
**I want** logs estructurados, captura de errores con Sentry y métricas reales de Core Web Vitals desde el día 1,
**so that** detecto problemas en producción sin depender de reportes manuales y entiendo la performance real de los usuarios.

## Acceptance Criteria

1. Logger estructurado configurado (Pino) emitiendo JSON en server-side; consumido por Vercel Logs.
2. Sentry instalado (`@sentry/nextjs`) con DSN por env var; captura excepciones server y client.
3. Un error provocado en dev (botón temporal de "throw" o ruta `/api/dev/error`) aparece en el dashboard Sentry.
4. Vercel Speed Insights habilitado en el proyecto; reporta LCP/INP/CLS reales en el dashboard.
5. Configuración de Sentry con sample rates: 100% errores, 10% transactions en preview/prod, 0% en dev (override solo si necesario).
6. Vitest instalado + configurado (`vitest.config.ts`) con primer test pasando (smoke test).
7. CI workflow actualizado para correr Vitest real (no `--passWithNoTests`).
8. Documentación de cómo agregar nuevos events / breadcrumbs en el código (`docs/operations/observability.md`).

## Dev Notes

### Sample rates de Sentry

- **Errors:** 100% siempre (`tracesSampleRate` controla traces, no errors).
- **Traces:** 10% en producción/preview (suficiente para entender perf sin saturar quota).
- **Replays:** 0% en MVP (consume mucho quota free).

### Por qué Pino sobre console

- JSON estructurado consumible por agregadores.
- Niveles configurables por env.
- Sin overhead en producción.
- Estándar de la industria Node.

### Riesgos asociados

- **Sentry free tier:** 5k errores/mes. Si crece, evaluar plan o reducir sample rate.
- **Pino + Vercel Edge runtime:** Pino funciona en Node runtime, **no en Edge**. Para edge functions usar `console.log` con JSON estructurado manual o un wrapper.

### Testing

- Story 1.9 incluye instalación + smoke test de Vitest.
- Las stories posteriores DEBEN agregar sus tests en cada feature.
